# ℹ️ Дополнительные компоненты

AutoStars не требует отдельной установки .NET Framework для запуска Python-версии проекта.

Для работы достаточно Python, зависимостей из `requirements.txt` и корректно заполненного `config.json`. Если его нет, проект создаст копию из `config.example.json` при первом запуске.
